## Сборка и unit tests

`gradlew.bat test bootJar` завершён с BUILD SUCCESSFUL. Проверены модульные зависимости domain/application/adapters; собраны три исполняемых JAR и библиотека contracts.

Тесты проверяют регистрацию и хеш пароля, отказ аутентификации, восстановление заказа, расчёт по каталожной цене, валюты, складские инварианты и шаги саги. ## Docker и интеграция

Compose с docker-compose.local.yml успешно собрал runtime-образы. Все три приложения и PostgreSQL/Redis/Kafka достигли healthy. Kafka UI запущен на 8085.

`python scripts/integration.py` завершён с PASS на настоящем стенде. Проверены:

1. Отказ 401 без JWT и регистрация двух независимых пользователей.
2. Профиль, корзина, категория и расчёт скидки купона.
3. Создание/повторное чтение товара через PostgreSQL и Redis.
4. gRPC-получение цены: переданная клиентом цена 0.01 заменяется каталожной ценой 10; две единицы стоят 20.
5. Успех саги: PAID, остаток 5 → 3, баланс 100 → 80.
6. Чужой заказ возвращает 404.
7. Недостаток средств: CANCELLED и возврат зарезервированной единицы; остаток остаётся 3.
8. Недостаток товара: CANCELLED без изменения остатка.
9. Точное повторение ORDER_CREATED из outbox с тем же eventId через Kafka console producer: повторного уменьшения остатков и баланса нет.
10. Два конкурентных заказа на последнюю единицу: один PAID, второй CANCELLED, остаток 0.

Скрипт создаёт уникальные тестовые записи и не удаляет их. Запуск рассчитан на локальный/CI Compose с открытыми HTTP-портами и доступным Docker CLI. На сервере через домен применяются ручные API-сценарии из presentation.md.
